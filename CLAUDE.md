# Week 13 Shorts project

For a Shorts production request, delegate source inspection to `shorts-input-reviewer` and brief review to `shorts-edit-reviewer`. These may run in parallel. Gather both reports before choosing the source and brief. Use the user's approved script if provided. For a demo without a source, use the original synthetic clip generated by the pipeline.

Run the matching local command in README.md. After the render, ask `shorts-output-reviewer` to read the actual output directory. Describe the media files that were produced and confirmed and flag missing validation. A human still reviews the sound and framing in context. Ask for explicit authorization before any upload or publication.
